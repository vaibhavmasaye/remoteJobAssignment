## 📋 Variables You Need to Set (REQUIRED FOR DEPLOYMENT)

### 1. **ADMIN_IP_ALLOWLIST** ✅ DONE
- **Current Value**: `*` (all IPs allowed)
- **Purpose**: Restricts access to admin endpoints
- **For Testing**: `*` is fine (allow all)
- **For Production**: Change to specific IPs like `203.0.113.1,198.51.100.2`

### 2. **HUBSPOT_PORTAL_ID** ✅ DONE
- **Current Value**: `27945619`
- **Purpose**: Your HubSpot account ID
- **How to Get**:
  1. Go to https://app.hubapi.com
  2. Click Settings (gear icon) → Account settings
  3. Look for "Portal ID" on the right side
  4. Copy it

## ⚠️ Optional Variables (Leave Empty if Not Using)

### 3. **STRIPE_SECRET_KEY** (OPTIONAL)
- **Current Value**: Empty
- **Purpose**: Secret key for Stripe API access
- **When to Set**: Only if you want to sync Stripe payments
- **How to Get**:
  1. Go to https://dashboard.stripe.com
  2. Click **Developers** → **API Keys**
  3. Copy the **Secret Key** (starts with `sk_live_` or `sk_test_`)
  4. Paste in `.env`
- **If Not Using**: Leave empty (app will disable Stripe sync)

### 4. **STRIPE_WEBHOOK_SECRET** (OPTIONAL)
- **Current Value**: Empty
- **Purpose**: For Stripe webhook validation
- **When to Set**: Only if using Stripe webhooks
- **How to Get**:
  1. In Stripe Dashboard → **Developers** → **Webhooks**
  2. Create endpoint for `https://YOUR_DOMAIN/webhooks/stripe`
  3. Copy the **Signing Secret** (starts with `whsec_` or `we_`)
- **If Not Using**: Leave empty

### 5. **GOOGLE_WEBHOOK_TOKEN** (OPTIONAL)
- **Current Value**: Empty
- **Purpose**: For validating Google Calendar webhooks
- **When to Set**: Only if using Google Calendar webhooks
- **How to Get**:
  1. Generate a random secure token (32+ characters)
  2. Use: `openssl rand -hex 16` to generate
  3. Paste in `.env`
- **If Not Using**: Leave empty

### 6. **GOOGLE_WEBHOOK_CHANNEL_ID** (OPTIONAL)
- **Current Value**: Empty
- **Purpose**: For Google Calendar push notifications
- **When to Set**: Only if using Google Calendar webhooks
- **How to Get**: Auto-generated by Google Calendar API when you set up webhooks
- **If Not Using**: Leave empty

### 7. **GOOGLE_CALENDAR_TIME_MIN** (OPTIONAL)
- **Current Value**: Empty
- **Purpose**: Filters calendar events to only those after this timestamp
- **Format**: ISO 8601 format: `2026-01-01T00:00:00Z`
- **Example**: `2026-07-01T00:00:00Z` (sync events from July 1, 2026 onwards)
- **If Not Using**: Leave empty (syncs all events)

### 8. **SENTRY_DSN** (OPTIONAL)
- **Current Value**: Empty
- **Purpose**: For error tracking and monitoring with Sentry
- **When to Set**: Only if you have a Sentry account
- **How to Get**:
  1. Go to https://sentry.io
  2. Create a project or select existing
  3. Copy the **DSN** (looks like `https://xxx@xxx.ingest.sentry.io/123456`)
  4. Paste in `.env`
- **If Not Using**: Leave empty (errors only logged to console)

## ❓ FAQ

**Q: Can I leave all optional variables empty?**
A: Yes! The app will work fine. These are only needed if you want those specific features.

**Q: Should I set STRIPE_SECRET_KEY?**
A: Only if you want to sync Stripe payments. If not, leave empty and Stripe sync won't run.

**Q: What does ADMIN_IP_ALLOWLIST=* mean?**
A: It allows anyone from any IP to access admin endpoints. For production, replace with specific IPs.

**Q: How do I generate GOOGLE_WEBHOOK_TOKEN?**
A: Run: `openssl rand -hex 16` in terminal to get a random 32-character token.

**Q: Where do I add these to Render?**
A: Go to Render Dashboard → Your Service → Environment tab → Add variables one by one.

## 🔐 Security Notes

- **ADMIN_IP_ALLOWLIST**: Use `*` for testing only. For production, add specific IPs
- **STRIPE_SECRET_KEY**: Never share this. Keep it secret
- **SENTRY_DSN**: Can be public (it's meant to be)
- **Never commit `.env` file to Git** - it's already in `.gitignore`
